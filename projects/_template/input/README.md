# Input views

Export each SketchUp scene as an image here (**File > Export > 2D Graphic**, PNG):

- Name the file after the scene, starting with the view type: `EXT-01 Entrance.png`,
  `INT-02 Living.png`, `AER-01 Site.png`, `DET-01 Facade joint.png`.
- Use the same SketchUp **style** for every export: textures on, shadows on, edges thin
  or off, no sketchy edges, no watermark. The renderer follows what it sees.
- About 2000 px on the long side is plenty. The frame (aspect ratio) of each
  image is kept in the render.
